## Assets and provenance

- App icon, logos, promotional art, card art, colors: copied from the parent project's `public` directory.
- Real app screenshots: captured at 430 × 932 CSS pixels, 2× resolution, from the running Vite app in an isolated browser context. Alex, Mia, Leo, and Zoe are sample data. The production app source and existing user data are unchanged.
- Typography: Segoe UI, the actual Windows system fallback used by the app's `Inter, ui-sans-serif, system-ui, sans-serif` stack. No Inter font file is bundled in the original app. Font files are from this computer's Windows installation.
- Voice-over: ElevenLabs, Liam — Energetic, Social Media Creator, `eleven_v3`. The selected take is saved as `public/audio/voiceover.mp3`.
- Card transition effect: ElevenLabs Sound Effects v2, saved as `public/audio/whoosh.mp3`.
- Music: original deterministic 120 BPM electro-funk composition, synthesized locally in `scripts/score.mjs`. Includes bass, chord stabs, plucked arpeggios, drums, and a resolved closing sting. The ElevenLabs music request was rate-limited and produced no music.
- Additional cut accents: original synthesized sound design, also generated by `scripts/score.mjs`.

## Editing and rendering

Run `npm run dev -- --no-open --port=3001` from this folder. Select `Flip7-Companion`. Each of the six scenes is also available separately in the Scenes folder. Audio stems and timings remain editable in the main composition.

Render: `npx remotion render Flip7-Companion out/Flip7-Companion-Showreel-1080p.mp4 --codec=h264 --crf=18 --concurrency=4`.

Regenerate music and accents: `node scripts/score.mjs`.

Recapture screens: start the parent app on port 5173, then run `node scripts/capture.mjs`. The script uses installed Microsoft Edge and an isolated, temporary browser context.
